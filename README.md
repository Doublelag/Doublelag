# Jose Angel (Doublelag)

Creador de contenido en YouTube y, desde hace un tiempo, también el que se escribe las herramientas que necesita. Vivo en Sevilla.

Construyo cosas para resolver problemas concretos: automatizar el trabajo repetitivo del canal, administrar servidores de juego sin depender de paneles, y productos que se puedan usar desde el móvil.

## En lo que trabajo

**[Frigo](https://github.com/Doublelag/frigo)** · Next.js · TypeScript · Claude API
Web app que identifica los alimentos de una foto de la nevera o de un ticket de compra, lleva el control de las caducidades y propone recetas para aprovechar lo que está a punto de caducar. Funciona sin conexión, se instala en el móvil y lleva sus propios tests.

**[Comparador de hosting de Minecraft](https://github.com/Doublelag/comparador-hosting)** · Python · Cloudflare Workers
Sitio generado con scripts propios: calculadora de RAM, fichas de proveedores y comparativas. Publicado en Cloudflare, con versión en inglés.

**Herramientas internas** (privadas)
Administración de un servidor de Minecraft por API, automatización de gestiones del canal y scripts de análisis.

## Con lo que me manejo

TypeScript · Python · Next.js · React · Tailwind · Node · PowerShell · Cloudflare Workers · Vercel · APIs de IA
